# आरती भुवनसुंदराची
आरती भुवनसुंदराची ।। इंदिरावरा मुकुंदाची ।। धृ० ।।

पद्मसम पादयुग्मरंगा ।। ओंवाळणी होति भृंगा ।।

नखमणि स्त्रवताहे गंगा ।। जे कां त्रिविधतापभंगा ।।

वर्तुळ गुल्फ भ्राजमानें ।। किंकिणिव्कणित नाद घणघणित वांकिवर झुणित नेपुरें झनन मंजिराची ।।

झनन ध्वनी मंजिराची ।। आरती भुवन० ।। १ ।।

पीतपट हाटकतप्तवणीं ।। कांची नितंब सुस्थानीं ।।

नाभिची अगाध हो करणी ।। विश्वजनकाची जे जननी ।।

त्रिवलीललित उदरशोभा ।। कंबुगळा विलंबित झळाळ कौस्तुभ सरळ बाहु श्रीवत्सतरलमणिमरण कंकणाची ।।

प्रीती बहु जडित कंकणाची ।। आरती भुवन० ।। २ ।।

इंदुसम आस्य कुंदरदना ।। अधरारुणार्क बिंबवदना ।।

पाहतां भ्रांति पडे मदना ।। सजलमेघाब्धि दैत्यदमना ।।

झळकत मकरकुंडलाभा ।। कुटिलकुंतली मयूरपत्रावली वेष्टिले तिलक भालिं ।।

केशरी झळाळित कृष्णकस्तुरीची ।। अक्षता काळि कस्तुरीची ।।

आरती भुवन० ।। ३ ।। कल्पद्रुमातळीं मूर्ती ।।

सौदामिनी कोटिदीप्ती ।। गोपीगोपवलयं भवतीं ।

त्रिविष्टप पुष्पवृष्टि करिती ।। मंजुल मधुर मुरलिनादें ।।

चकित गंधर्व चकित अप्सरा सुरागिरिवरा ।। कर्पूरधरा रतींनें प्रेमयुक्त साची ।।

आरती ओवाळित साची ।। आरती भुवन० ।। ४ ।।

वृदावनींचिये विहरणीं ।। सखे गे कृष्ण माय बहिणी ।।

श्रमलों भवाब्धिचे फिरणीं ।। अतां मज ठाव देईं चरणीं ।।

अहा हे पूर्ण पुण्यश्लोका ।। नमितों चरण शरण मी ।।

करुणा येऊं दे विशाळपाणी ।। कृष्ण नेणतें बाळ आपुलें राखिं लाज याची ।।

दयानिधे राखिं लाज याची ।। आरती भुवन० ।। ५ ।।​
