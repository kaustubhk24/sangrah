# करितो वंदना गजानना

करितो वंदना गजानना

तुम्ही हासत नाचत या अंगणा ||१||

चौदा विद्येचे तुम्हीच करता

तुम्हीच आधी तुम्हीच अंता

पूर्ण करिशी आमची मनोकामना

करितो वंदना गजानना ||२||
