# विठ्ठल पाहुणा आला माझ्या घरा

विठ्ठल पाहुणा आला माझ्या घरा

लिंब लोन करा सावळ्याला ||धृ||

दूरच्या भेटीला बहु आवडीचा

जीवन सरिता नारायण ||१||

सर्व माझे गोत्र, मिळाले पंढरी

मी माझ्या माहेरी धन्य झालो ||२||

तुका म्हणे माझा आला सखा हरी

संकट निवारी पांडुरंग ||३||
